# User Guide

Use `*` for multiplication and `**` for powers. Examples: `x**2 + 2*x + 1`, `sin(x)`, `sqrt(2)`, `3+2*i`.

- **Complex numbers:** enter two values and select arithmetic.
- **Algebra:** simplify, expand, factor or solve an equation such as `x**2 - 4 = 0`.
- **Calculus:** differentiate, integrate or calculate a limit.
- **Matrices:** enter rows separated by semicolons and entries by commas, e.g. `1,2;3,4`.
- **Graphing:** enter a real-valued function of `x`.
- **Regression:** enter matching comma-separated x and y observations.
- **Statistics:** enter comma-separated numeric values.
