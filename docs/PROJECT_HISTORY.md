# Project History and Attribution

The project began as a group assignment around 2021, titled **Complex Math Calculator using SYMPY**. The surviving PowerPoint presentation is the reference material; the original source code was not available for this redevelopment.

The presentation identifies complex-number calculations, algebra, calculus, regression analysis, a Python calculator interface and output demonstrations.

## Rebuilt edition
NUMERIX is a new implementation based on the original project theme. Its code organisation, interface, tests and additional modules belong to this redevelopment.
